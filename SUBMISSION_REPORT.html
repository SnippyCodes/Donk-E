1. End-to-End Architecture & Truth Hierarchy

MULTI-ROOT INGEST (2.54s, 0 LLM calls) ──▶ RAW SQLITE (39,567 inspections, 5,665 repairs, 90 reg events, 140 notes)
  ├── rules.yaml (SOP & OM-T200/T350/T500 manual thresholds with citations)
  ├── report_facts (1,509 free-text repair MD reports, 100% regex coverage)
  └── docs_fts (SQLite FTS5 BM25 search engine index)
APPEND-ONLY LEDGER ──▶ MATERIALIZED DERIVED VIEWS (eff_inspection, well_now, spills rebuilt in <20ms)
AGENT LOOP & GUARDRAILS ──▶ SCHEMA-DRIVEN GENERATIVE UI (8 visual block types)

The Truth Hierarchy: Deterministic Python/SQLite code owns 100% of arithmetic, counts, and dates (Zero LLM Math). In eff_inspection, is_producing is calculated as wellhead_temp_c - ambient_temp_c >= threshold (15.0°C for T200, 20.0°C for T350). When recorded status contradicts empirical telemetry, it is marked as out-of-date. Downtime is strictly computed as 7 days per non-producing weekly inspection.

2. Two-Level Memory & Scoped Feedback

The append-only ledger permanently preserves historical audits while enabling runtime operational corrections (raw_correction, analysis_correction, rule_override, claim). Rule overrides resolve via well > well_type > fleet > manual. In Q14, Michael Turner's T350 2-repair RCA override applies strictly to T350 wells, completely contained from T200 wells. Private conversations enforce code-level isolation via WHERE user_id = ?.

4. Post-Mortem: What Broke During QA & How We Fixed It

1. Gemma 4 <|tool_call> Token Leakage: Intercepted raw tokens in llm.py with an AST regex parser, forcing structured tool execution and Turn 2 synthesis.
2. Keyword Argument Drift: Handled parameter aliases (window vs from_date/to_date) via universal normalization in registry.py and resolver.py.
3. Duplicate Markdown Pipe Tables: Engineered an intelligent table stripper in guardrails.py to purge raw pipe tables when structured visual blocks are rendered.
4. Cross-Scope Rule Contamination: Enforced strict scope containment in params.py (well > well_type > fleet) bound to reactive view rebuilds.
